# The Secret Game World

Игра доступна по онлайн-ссылке без регистрации и входа.

Браузерная игра для группового урока английского A1 по исходному сценарию `The_Secret_Game_World_A1_50min.md`.

## Запуск

Откройте `start-game.cmd` или выполните из папки проекта:

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Затем откройте http://127.0.0.1:8080. Для запуска нужен Python 3; npm, платные API и интернет игре не нужны. Можно раздать папку `dist` любым статическим HTTP-сервером. Простое открытие HTML через `file://` не подходит для ES-модулей.

## Управление

«Начать путешествие» → три короткие сцены → карта → 33 миссии → победа → устное закрепление. Учитель управляет игрой, дети отвечают вслух. В заданиях сортировки выберите объект, затем ячейку, либо перетащите объект. Уже заполненную ячейку можно очистить нажатием.

TEACHER открывает боковую панель: ключи ответов, подсказки, сброс и пропуск задания, переход назад и далее, таймер урока, повтор и пауза памяти, ручная корректировка XP. Финальный замок пропустить нельзя. Кристалл выдаётся и при пропуске заданий; XP за пропуск не начисляются. Повторное решение не начисляет дополнительные XP. Максимум 330 XP.

Звук по умолчанию выключен. SOUND включает синтезированные короткие сигналы. FULL SCREEN использует API браузера, поддержка зависит от браузера. LOW MOTION уменьшает анимации; системное предпочтение также учитывается.

Прогресс сохраняется в localStorage этого браузера: Кнопка «Начать путешествие» продолжает сохранённую сцену, если прогресс уже есть. NEW GAME запрашивает подтверждение. Сохранение не синхронизируется между устройствами. Имена и персональные данные детей не собираются.

## Тайминг 50 минут

| Этап | Минуты урока |
|---|---|
| Вступление и карта | 00:00–03:00 |
| Rainbow Arcade: 7 миссий | 03:00–13:00 |
| Number City: 9 миссий | 13:00–24:00 |
| Animal Kingdom: 12 миссий | 24:00–41:00 |
| Glitch King: 5 миссий | 41:00–48:00 |
| Победа и закрепление | 48:00–50:00 |

Тайминг рекомендательный: задания не завершаются автоматически. Только Memory Flash скрывает объекты через 15 секунд. Продолжительность устного обсуждения регулирует преподаватель.

## Файлы и проверка

- `dist/data.js`: сценарий и точные ключи всех 33 миссий.
- `dist/game.js`: состояния, механики, сохранение и интерфейс учителя.
- `dist/art.js`: локальные SVG-иллюстрации для заданий.
- `dist/assets`: новый комплект из 83 изображений, оптимизированных в WebP. Отдельные спрайты животных используются в выборе ответов, счёте, памяти, силуэтах и сортировке; новые сундуки, карты памяти, цветовые карточки и интерфейс встроены в игровые сцены. C06 и A09 используют готовые иллюстрации поиска отличий с тремя заранее заданными зонами на правой картинке.
- `verify.mjs`: проверка всех 33 миссий через обработчики приложения в Node VM, включая ошибки, повторный XP, 15 секунд памяти, сортировки, пропуски, 3 кристалла и код 324. Запуск: `node verify.mjs`.

Добавлены ещё 22 ассета из `secret_game_world_extra_assets_codex`: лягушка, фламинго, медведь, краб, предметы, локации и варианты синих/оранжевых роботов. В C05 исправлена раскладка: четыре одинаковые карточки 2×2, предметы ограничены размерами карточки, без перекрытий. Стили и модули имеют версию в URL для обновления браузерного кеша.

Автоматические проверки логики и формируемой разметки выполнены. Исправленная сцена Memory Challenge визуально проверена в браузере при 1280×720. Native fullscreen/звук и реальный проектор отдельно не проверялись.
